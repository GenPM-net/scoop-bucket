# GenPM Scoop bucket

```powershell
scoop bucket add genpm https://github.com/GenPM-net/scoop-bucket
scoop install genpm/genpm
```

Native `genpm` binary from [GenPM-net/genpm-releases](https://github.com/GenPM-net/genpm-releases), checksum-verified.
Other ways to install: https://genpm.net/docs/install
